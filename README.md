# SWC2623 Software Development Paradigms

## Smart Learning Pathway and Certification System

This repository contains the source code and final report for the SWC2623 Software Development Paradigms coursework.

## Project Structure

- Part A - Haskell: `Part_A_Haskell/Source.hs`
- Part B - Prolog: `Part_B_Prolog/Source.pl`
- Part C - Python: `Part_C_Python/Source.py`
- Final Report: `Report/Final Pdf Report.pdf`

## Software Requirements

- Python 3.14.7
- GHC 9.10.3
- SWI-Prolog 10.0.2 (x64-win64)

## How to Run

### Part A - Haskell

Open the terminal in the `Part_A_Haskell` folder and run:

`runghc Source.hs`

### Part B - Prolog

Open `Source.pl` using SWI-Prolog and run the required queries.

### Part C - Python

Open the terminal in the `Part_C_Python` folder and run:

`python Source.py`

## Report

The final coursework report is available in the `Report` folder.
